# A/B-тест: анализ конверсии в e-commerce

Аналитический проект по оценке результатов A/B-теста в e-commerce.

Цель проекта — определить, влияет ли вариант **V1** на конверсию по сравнению с контрольной группой **C**, проверить статистическую значимость эффекта и оценить устойчивость результата в различных сегментах.

---

## Цель анализа

Основная метрика эксперимента — **конверсия (CR, Conversion Rate)**.

Проверяются гипотезы:

- **H₀:** конверсия в группах C и V1 одинакова;
- **H₁:** конверсия в группах C и V1 различается.

Уровень статистической значимости:

**α = 0,05**

## Данные

Период эксперимента:

**01.02.2021 — 16.02.2021**

Объём данных:

**1 048 575 наблюдений**

Распределение наблюдений между группами:

| Группа | Наблюдения | Доля |
|---|---:|---:|
| C | 1 000 000 | 95,37% |
| V1 | 48 575 | 4,63% |

Датасет содержит следующие признаки:

- экспериментальная группа;
- дата;
- источник трафика;
- тип устройства;
- язык браузера;
- статус авторизации;
- регион;
- признак возвращаемости;
- конверсия.

В данных отсутствует уникальный идентификатор пользователя, поэтому невозможно проверить, соответствует ли одна строка одному уникальному пользователю.

---

## Методология

Для анализа A/B-теста использовались:

- **z-test для двух долей** — сравнение общей конверсии C и V1;
- **95%-й доверительный интервал** для разницы конверсий;
- абсолютный прирост в процентных пунктах;
- относительный прирост конверсии;
- **χ²-тест** — проверка баланса категориальных признаков между группами;
- **Cramer's V** — оценка величины различий в составе групп;
- сегментный анализ по источникам трафика и типам устройств;
- **поправка Holm** для множественных сравнений.

---

## Основной результат A/B-теста

| Показатель | C | V1 |
|---|---:|---:|
| Наблюдения | 1 000 000 | 48 575 |
| Конверсии | 100 092 | 5 272 |
| CR | 10,01% | 10,85% |

Результат:

- абсолютный прирост: **+0,84 п.п.**
- относительный прирост: **+8,43%**
- 95%-й доверительный интервал разницы: **[+0,56; +1,13] п.п.**
- p-value: **1,51 × 10⁻⁹**

Различие между группами статистически значимо.

---

## Проверка баланса групп

Распределение тестовой группы V1 по дням эксперимента оставалось относительно стабильным.

По большинству категориальных признаков существенных различий между группами не обнаружено.

Наиболее заметное различие связано с **типом устройства**:

- χ² = 1223,869
- p-value < 0,001
- Cramer's V = 0,0342

Несмотря на статистическую значимость, величина связи остаётся небольшой.

По признаку возвращаемости также обнаружено статистически значимое различие:

- χ² = 5,199
- p-value = 0,0226
- Cramer's V = 0,0022

Размер этого различия практически незначителен.

---

## Анализ по типам устройств

| Устройство | CR C | CR V1 | Прирост, п.п. | Относительный прирост | p-value Holm | Значимо |
|---|---:|---:|---:|---:|---:|---|
| Android | 10,06% | 11,50% | +1,44 | +14,29% | 0,0057 | Да |
| Desktop | 9,94% | 11,52% | +1,59 | +15,97% | <0,0001 | Да |
| iPhone | 10,01% | 10,10% | +0,09 | +0,91% | 0,7790 | Нет |
| Mweb | 10,03% | 10,64% | +0,61 | +6,07% | 0,0062 | Да |

После поправки Holm статистически значимый прирост сохраняется для:

- **Android**
- **Desktop**
- **Mweb**

Для **iPhone** статистически значимого различия не обнаружено.

---

## Анализ по источникам трафика

После поправки Holm статистически значимый эффект V1 сохраняется для:

- **Direct**
- **Organic**

Для остальных источников статистически значимого различия после поправки на множественные сравнения не обнаружено.

---

## Ограничения анализа

При интерпретации результата необходимо учитывать несколько особенностей данных.

Группы существенно различаются по количеству наблюдений:

- C — 95,37%
- V1 — 4,63%

При этом доля V1 была относительно стабильной по дням. Без информации об ожидаемом распределении трафика такое соотношение нельзя однозначно считать ошибкой экспериментального дизайна.

В данных отсутствует уникальный идентификатор пользователя. Поэтому невозможно определить, соответствует ли каждая строка уникальному пользователю, а полностью совпадающие строки нельзя автоматически считать ошибочными дублями.

Также выявлено небольшое различие в составе групп по типам устройств, которое следует учитывать при интерпретации общего результата эксперимента.

---

## Итог

Вариант **V1 показал статистически значимый рост общей конверсии**:

**10,01% → 10,85%**

Абсолютный прирост составил около **+0,84 п.п.**, относительный — **+8,43%**.

Положительный эффект сохраняется в большинстве исследованных сегментов по типам устройств, однако его величина неоднородна.

Вариант V1 может рассматриваться как **кандидат на внедрение**.

Перед принятием окончательного решения рекомендуется подтвердить корректность распределения трафика между экспериментальными группами и учитывать различия эффекта между типами устройств.
